# Новые крестики-нолики. Учебная практика
## Описание проекта
Автор проекта: Байбак Светлана Юрьевна, студент Санкт-Петербургского Государственного Университета Аэрокосмического приборостроения (ГУАП), гр.4526, направление 09.03.02<br>
Данный проект представляет собой игру, созданную в рамках учебной практики. При создании игры использовался движок Unity, язык программирования C#, редактор кода Visual studio, Adobe Illustrator и система контроля версий Git (сервис Github). За основу игры взяты классические крестики-нолики, при этом добавлена возможность выбрать режим игры: "С другом и монеткой" (далее "С другом") или "Классический с ПК" (далее "С ПК")<br>
1) Режис "С другом" предполагает игру двух игроков. Перед каждым ходом у игроков есть выбор, кинуть монетку и поставить выпавшую фигуру (X/0), или стереть любую фигуру на доске
2) Режис "С ПК" предполагает игру одного игрока против ПК<br>

## Технические особенности и установка
Данный проект доступен пользователям, установившим движок Unity. Необходимо скачать все файлы, представленные в данном репозитории, Для включения необходимо открыть проект в Unity и нажать кнопку Play, для паузы - Pause (Ctrl+P). Клики по клеткам осуществляются при помощи мыши.
