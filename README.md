# Новые крестики нолики. Учебная практика
## Описание проекта
Автор проекта: Байбак Светлана Юрьевна, студент Санкт-Петербургского Государственного Университета Аэрокосмического приборостроения (ГУАП), гр.4526, направление 09.03.02<br>
Данный проект представляет собой игру, созданную в рамках учебной практики с использованием движка Unity и языка программирования C#. За основу игры взяты классические крестики-нолики, при этом добавлена возможность выбрать режим игры: "С другом и монеткой" (далее "С другом") или "Классический с ПК" (далее "С ПК")<br>
